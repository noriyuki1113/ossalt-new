Traefik（トラフィック）は、インターネットからのアクセスを、内側で動いているアプリに振り分けるための、リバースプロキシです。Dockerなどのコンテナを自動で見つけて、振り分けの設定を作ってくれるのが特徴です。1台のサーバーで、複数のアプリを、それぞれ別のドメインで公開するときによく使われます。

### できること

- **自動での検出**：新しいコンテナを起動すると、その設定（ラベル）を読んで、振り分けのルールを自動で追加します。再起動は要りません。
- **HTTPSの証明書の自動取得**：Let's Encryptの証明書を自動で取得し、更新します。
- **管理画面**：現在のルールや状態を、ブラウザで確認できます。
- **そのほかの機能**：アクセスの負荷分散、認証の追加、通信の制限などの機能を、部品を足す形で使えます。

### 向いている使い方

- 1台のVPSで、Dockerで複数のオープンソース（Wiki、チャット、監視など）を動かし、それぞれにHTTPSの独自ドメインを付けたい。

APIの管理まで必要な場合は、[Kong](/tools/kong/)のようなAPIゲートウェイも比べてみてください（比較は「[KongとTraefikの違い](/compare/kong-vs-traefik/)」）。

### 注意点

- **管理画面を、インターネットに公開しないでください。** 内部の構成が見えてしまいます。公開する場合は、認証をかけ、アクセスできる場所を制限しましょう。
- **Dockerの管理用の接続口（ソケット）を、安易に渡さないでください。** コンテナの検出のために必要ですが、権限が強いので、読み取り専用にするなどの対策をします。
- 設定の方法が複数あり（ファイル、ラベルなど）、最初は少し戸惑います。
- ライセンスはMITです。

[AWS API Gatewayの代替](/alternatives/aws-api-gateway/)のページも参考にしてください。
