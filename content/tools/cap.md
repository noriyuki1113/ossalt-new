Cap（キャップ）は、READMEで「Loomのオープンソースの代替」と説明される、画面録画と共有のツールです。画面・カメラ・マイクを録画し、リンクで共有したり、動画として書き出したりできます。

### できること（READMEの記載）

- **2つの録画モード**：Instant Modeは、録画しながらアップロードし、止めるとすぐに共有リンクが得られます。Studio Modeは、手元に録画して、背景・ズーム・トリミング・字幕などを編集してから書き出します。
- **共有と共同作業**：コメント、リアクション、文字起こし、閲覧の分析、チームのワークスペースがあります。
- **Cap AI**：タイトル、要約、チャプター、字幕、文字起こしを自動で作ります。
- **Loomからの移行**：既存のLoomの動画を取り込めます。
- **保存先を選べる**：Cap Cloud、自分のS3互換のストレージ（AWS S3、Cloudflare R2、Backblaze B2、MinIO、Wasabiなど）、手元だけの保存、フルセルフホストから選べます。独自ドメインでの共有ページも使えます。

デスクトップアプリは、macOSとWindows向けです。Webのダッシュボードで、録画の閲覧・共有・管理をします。

### 自前で運用するには

READMEによると、Docker Composeで動かせます（リポジトリを取得し、`docker compose up -d`、`http://localhost:3000`）。そのほか、Railwayのテンプレートや、CoolifyのDocker Composeファイルも案内されています。本番に出す前に、公開URLの設定と、初期のシークレットの置き換えが必要だとREADMEにあります。デスクトップアプリからは、設定の「Cap Server URL」で、自分のサーバーを指定します。

### 向いている人

- 画面録画を、チームで共有する仕組みを持ちたい人。
- 録画データの保存先を、自分で決めたい人。

### 向いていない人

- macOS・Windows以外のデスクトップで録画したい人。

### 注意点（ライセンス）

READMEのLicenseの節によると、`cap-camera*` と `scap-*` のクレート群はMITライセンスで、**そのほかの大部分はAGPLv3**です。第三者の部品は、それぞれの元のライセンスに従います。掲載データの表示（MIT）だけを見ず、READMEのこの記載を確認してください。AGPLv3は、改変したものをネットワーク越しに他の人へ提供する場合、ソースの公開が必要なライセンスです。
