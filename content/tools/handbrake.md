HandBrake（ハンドブレーキ）は、すでに持っている動画を、別の形式の動画ファイルに作り直す（変換する）ソフトです。公式は、スマートフォン、タブレット、テレビのメディアプレーヤー、ゲーム機、パソコン、ブラウザなどで再生できる動画に変換できると説明しています。Linux・Mac・Windowsで使えます。画面の日本語翻訳を確認できています。

サーバーに入れて使うものではなく、**自分のパソコンにインストールして使うアプリ**です。このサイトでは、Adobe Media Encoder（アドビの動画の書き出し・変換ソフト）の代わりの候補として載せています。

### できること

- **いろいろな動画を読み込める**：公式は、ビデオカメラ、スマートフォン、画面録画、DVDやBlu-rayのディスクなど、一般的な動画の形式の多くを読み込めるとしています。変換後のファイルは、MP4・MKV・WebMです（CLIでは、MOV形式も選べます）。
- **プリセット（設定の組み合わせ）**：機器や用途に合わせた設定が、最初から用意されています。公式の分類は、一般向け、動画サイト向け（Vimeo・YouTubeなど）、機器向け（スマートフォン、タブレット、テレビ、ゲーム機など）、ハードウェア向け、制作向けです。目的に合う設定を選ぶだけで、細かい数値を決めずに変換できます。
- **ハードウェアでの高速な変換**：Intel Quick Sync Video、NVIDIA NVENC、AMD VCN、Windows on ARM向けのMedia Foundation、AppleのVideoToolboxを使う設定があります。対応する機器とドライバーが見つからない場合、その設定は使えなくなります。
- **映像の仕上げ**：インターレースの解除、ノイズの除去、切り抜き、色空間の変換などのフィルターがあります。HDRの動的メタデータ（HDR10+、Dolby Vision）を残す設定も、公式のコマンドライン説明に載っています。
- **音声の扱い**：AAC・AC3・E-AC3・Opus・MP3・FLACなどに変換できます。元の音声をそのまま使う（パススルー）設定もあります。
- **たくさんの動画をまとめて処理**：変換する動画を、順番に並べて（キュー）、まとめて処理できます。
- **コマンドラインでの利用**：`HandBrakeCLI` という、画面を使わない版があります。画面のアプリで作った処理待ち（キュー）を、CLIに読み込ませることもできます。

### Adobe Media Encoderとの違い

Adobe Media Encoderは、アドビの公式の説明で、Premiere Pro・After Effects・Audition・Character Animatorの書き出しを受け持つ「エンコードの仕組み」とされています。これらのアプリから書き出しを送ったり、指定したフォルダーに入れた動画を、自動で変換したり（ウォッチフォルダー）できます。アドビは、有料のサブスクリプション（Creative Cloud）に含まれる製品として提供していて、体験版も案内しています。

- **連携**：HandBrakeは、単独で使う変換ソフトです。Premiere ProやAfter Effectsから書き出しを受け取る仕組みや、ウォッチフォルダーに当たる機能は、今回確認した公式資料の範囲では見つかりませんでした。アドビの製品で動画を編集していて、書き出しをMedia Encoderに任せている場合は、その流れをそのまま置き換えるのは難しい可能性があります。
- **費用**：HandBrakeは無料です。Adobe Media Encoderは、Creative Cloudの契約に含まれます。
- **向く用途**：すでに完成している動画を、スマートフォンやテレビ、動画サイトに合う形式に変換するだけなら、HandBrakeで足りることが多いと考えられます。編集ソフトと一体で、書き出しを自動化したい場合は、Adobe Media Encoderのままのほうが合います。
- **同じ目的で使われるもの**：[FFmpegとの違い](/compare/ffmpeg-vs-handbrake/)も参考になります。FFmpegは、コマンドで操作する動画処理の道具です。HandBrakeは、内部でFFmpegなどを使っていると、公式のREADMEに書かれています。

### 必要なパソコンの条件

公式の「システム要件」にある、正式にサポートする最低ラインです。

- **プロセッサー**：AMD Ryzen・Threadripper・Epyc、Intel Core（第9世代以降）、Apple Silicon（M1以降）。
- **メモリー**：標準画質〜フルHD（480p〜1080p）の変換で、16GB以上。
- **保存容量**：アプリ本体で150MB。変換する動画のぶんは別に必要です。
- **画面**：1280×960以上。表示の拡大率を上げると、さらに広い画面が必要です。

この条件に合わないパソコンでも、動かせる場合はありますが、公式は推奨していません。

OSごとの対応の目安です（公式の一覧）。

- **Windows**：Windows 11が「サポート」、Windows 10は「非推奨（動くことはあるが、サポートなし）」です。Microsoftの「.NET Desktop Runtime」10.0が必要です。
- **Mac**：macOS 14（Sonoma）・15（Sequoia）・26（Tahoe）がサポート対象です。Intel MacとApple Siliconの両方で動きます。
- **Linux**：Flathubの配布（`flatpak install fr.handbrake.ghb`）が使えます。Ubuntu・Fedora・FreeBSDは、新しい版がサポート対象です。

### 使い始めるまでの流れ

1. 公式サイトから、自分のOS向けのHandBrakeを入れます（Windowsは、先に.NET Desktop Runtimeが必要です）。
2. 変換したい動画（ソース）を読み込みます。
3. 用途に合うプリセットを選びます。
4. 保存先とファイル名を決めて、変換を始めます。たくさんある場合は、キューに追加します。

### つまずきやすい点

- **変換には時間がかかります**：パソコンの性能と、設定（画質・エンコーダーの種類）で、大きく変わります。公式は、ハードウェア向けのプリセットを「最高の変換速度に向けて調整したもの」と説明しています。速度と画質・ファイルの大きさのバランスは、短い動画で試して確かめるとよいでしょう。
- **画質が下がることがあります**：動画を作り直す（再エンコード）ため、設定によっては、元より画質が下がります。元の動画は、変換の結果を確かめるまで消さないでください。
- **コピー防止のかかったディスク**：市販のDVD・Blu-rayには、コピー防止がかかっているものがあります。扱いは、公式の資料で確認してください。また、著作権法の扱いは国によって違います。ご自身で確認をしてください。

### ライセンスの注意

ライセンスは GPL-2.0 です。公式のライセンスのファイルでは、ほとんどのファイルがGPLv2で、一部のファイルは、GPLv2以降、LGPL 2.1以降、BSD・MIT系のライセンスです。いずれの場合も、組み立てた（コンパイルした）HandBrakeには、GPLv2の条件が適用されるとしています。

- **fdk-aac**：音声の変換部品（Fraunhofer AAC）は、GPLv2と両立しないライセンスのため、標準では含まれていません。自分でビルドして入れることはできますが、**そのバイナリは再配布できません**（公式のライセンスの説明）。
- **社内で使うだけ**の場合は、通常の利用になります。**改変して他の人に配る**場合は、GPLの条件（ソースの公開など）が関わるため、原文を確認してください。
