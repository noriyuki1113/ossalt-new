Semgrep（セムグレップ）は、ソースコードを実行せずに調べて、**危険な書き方やバグのパターンを見つける**静的解析のツールです。公式のREADMEでは「コードのための意味のあるgrep」と説明されています。単なる文字の検索とちがい、コードの意味を理解して探せます。

### できること

- **ルールを自作できる**：検査のルールを、普段書いているコードに近い形で書けます。`semgrep -e '$X == $X' --lang=py` のように、その場で検索もできます。
- **30以上の言語**：Python、JavaScript、TypeScript、Java、Go、PHP、Ruby、C/C++、Terraform、YAMLなどに対応しています。
- **公開のルール集**：コミュニティが作った2,000以上のルール（Semgrep Registry）を使えます。
- **CIやエディタで使う**：CIでプルリクエストを検査すると、**そのプルリクエストで新しく入った問題だけ**を報告できると書かれています。エディタや、コミット前の検査にも組み込めます。
- **コードは外に送られない**：公式の説明では、解析は手元やビルドの環境で行い、初期設定ではコードはアップロードされません。

Dockerでの導入方法を確認できています。

### SonarQubeとの違い

SonarQubeは、コードの品質やセキュリティの指摘を、サーバーの画面でまとめて管理するツールです。Semgrepの無料版は、**コマンドで動かす検査のエンジン**が中心で、ルールを自分で書きやすいのが特長です。画面での結果の管理や、チームでの運用の機能は、Semgrep AppSec Platform（無料と有料の枠あり）で提供されています。

### 始め方

公式のREADMEでは、`pipx install semgrep`、`uv tool install semgrep`、`python3 -m pip install semgrep` などで導入する方法が案内されています。Dockerのイメージ（`semgrep/semgrep`）で試すこともできます。プロジェクトのフォルダで `semgrep ci` を実行すると検査できます（`semgrep login` でのログインは任意です）。

### 注意点

- 公式のREADMEでは、**無料のCommunity Editionは、1つの関数やファイルの中しか解析できないため、セキュリティの検査では多くの問題を見逃す**と書かれています。ファイルをまたぐ解析や、依存しているライブラリの脆弱性の検査、秘密の情報の検出は、Semgrep AppSec Platform（公式の説明では無料と有料の枠があります）の機能です。料金と条件は公式の案内で確認してください。
- 社内のルールの検査や、明らかなバグのパターンの検出など、目的をはっきりさせて使うと効果が出やすいツールです。
- ライセンスはLGPL-2.1です。
