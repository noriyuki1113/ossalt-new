Continue（コンティニュー）は、エディタの中で**AIにコードを書いてもらったり、相談したりする**ための拡張機能です。GitHub Copilotと似た使い方ができますが、**使うAIのモデルを自分で選べる**のが大きな特徴です。

### できること

- **チャット**：選んだコードについて質問したり、修正を頼んだりできます。
- **コードの補完**：書いている途中のコードの続きを、AIが提案します。
- **編集**：範囲を選んで、「この関数をテストしやすく書き直して」のように指示できます。
- **モデルを選べる**：OpenAIやAnthropicなどのAPIのほか、[Ollama](/tools/ollama/)などで手元で動かすモデルも使えます。
- **VS CodeとJetBrains**：両方のエディタに対応しています。

### GitHub Copilotとの違い

GitHub Copilotは、GitHubが提供するサービスで、使えるモデルや送り先はサービスの側で決まります。Continueは、**どのモデルを使い、コードをどこに送るかを、自分たちで決められます**。手元で動かすモデルを使えば、コードを外部に送らずに使うこともできます。

### 注意点

- **「外部に送らない」のは、設定しだいです。** 外部のAPIのモデルを選べば、コードはそのサービスに送られます。社内のコードを扱う場合は、どのモデルを使ってよいかのルールを決めてください。
- 手元で動かすモデルは、最新の大規模なモデルより、提案の質が劣ることが多く、補完の速さは機械の性能に左右されます。
- AIの提案には、誤りや、ライセンスに注意が必要なコードが含まれる可能性があります。提案されたコードは、必ず人が確認してください。
- ライセンスはApache-2.0です。
