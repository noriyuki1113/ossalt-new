# 記事の下書き（未公開）

ここにある記事は**公開されません**（サイトのビルドは `content/blog/` だけを読む）。

AIが作った下書きは、自動では公開しない（Revenue Strategy 2.0 の方針）。公開の手順：

1. 運営者が内容を読み、事実（数値・手順・ライセンス）を出典で確かめる。
2. 実機で試していない手順を「検証済み」と書いていないか確かめる。
3. 問題なければ、ファイルを `content/blog/` に移し、`date`（公開日）を決め、先頭の `draft_*` の項目を消す。
4. `npm test` と `npm run build`（またはPRのCI）が通ることを確かめて、既定のブランチに入れる。

各下書きの先頭に、企画（読者の問題・OSSALTの独自の情報・収益の導線）と、確認した出典を書く。企画の一覧は `docs/revenue/CONTENT_BRIEFS.md`。
