## 選び方

- **APIゲートウェイとしての機能**：KongとApache APISIXは、認証・流量の制限・ログなどを備えた本格的なAPIゲートウェイです。Kongには有償版にしかない機能もあるため、必要な機能がどちらに含まれるか確認しましょう。
- **振り分けの自動化**：Traefikは、コンテナの起動を検知して振り分けの設定を自動で作るリバースプロキシです。API管理の機能は、KongやAPISIXほど多くありません。
- **ライセンス**：KongとApache APISIXはApache-2.0、TraefikはMITです。

## 移行するときの注意

- 認証、流量の制限、振り分けのルールは、移行先の設定の書き方で作り直す必要があります。
- AWS LambdaなどAWSのサービスと一体で使っていた機能は、そのままでは置き換えられないことがあります。つながっている先を一覧にして確認しましょう。
- ゲートウェイはすべてのAPIの入口になるため、止まれば全体が止まります。複数台での運用と、TLS証明書の自動更新を最初に設計してください。
