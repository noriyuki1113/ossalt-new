# 2026-10-25 海外向け公開前コンプライアンス監査（OSSALT）

> 対象: `noriyuki1113/ossalt-new` のソースコードと 2026-10-25 時点の `https://ossalt.jp/` 公開HTML。
> これは技術面の一次監査であり、サービス全体の法令適合や第三者サービスの運用状況を保証するものではありません。

## 対応済み（レビュー用ブランチ）

- **フォント外部通信**: `src/app/layout.tsx` でGoogle提供サーバーから直接CSSを取得していた。 `next/font/google` を使用して**ビルド時に取得し、本番はサイトのホストから配信**する方式に変更。３種類のフォントを維持。なおデプロイ後のNetwork検査が必要。
- **セッションリプレイ**: 調査したコードには録画用SDKの導入なし。アクセス解析に `cloud.umami.is/script.js` を使用しているが、これはセッションリプレイSDKと同一ではない。`scripts/privacy-guard.test.mjs` にリプレイSDKの追加を検出する静的テストを追加。CDN/GTM/外部管理画面などを含む全通信・設定を保証する検査ではない。
- **プライバシー説明**: Cookieを使わない＝外部へ個人情報が送信されない／あらゆる法域で同意不要、という断定を除外。Umami Cloudへの通信と録画未実装を明記。

## デプロイ後の合格条件

1. `npm test` と `npm run build` が成功する（本監査実行環境では未実施）。
2. `https://ossalt.jp/` を新規プライベートウィンドウで開きDevTools Networkを確認し、`fonts.googleapis.com` と `fonts.gstatic.com` へのフォント要求が**0件**である。
3. 画面の日本語／見出し／等幅文字のレイアウトをPC・iPhoneの両方で確認する。
4. ブラウザNetworkからサードパーティの解析リクエストを記録し、`cloud.umami.is` の実態・プライバシーポリシー記載内容の一致を確認する。
5. セッション録画ベンダーや不明なデータ転送が検出された場合は配信停止後に再評価する。
6. メール配信サービスの管理画面・ホスティング・認証・決済管理画面を確認し、コードだけでは見えない機能も監査する。

## DMCA代理人登録の実務手順

1. まず自社がDMCAのホスティング型セーフハーバー保護を必要とするか、対象の第三者コンテンツを洗い出して判断する。
2. `https://www.copyright.gov/dmca-directory/` でアカウントを作成し、サービス提供者の**正式名称、実在の住所（サービス提供者には私書箱不可）**、サービス・アプリの別名とURL、代理人の氏名/組織/住所/電話/メールを入力する。
3. 当局の案内する費用（現在1登録につき6米ドル）を支払い、正式登録の完了を確認する。代理人連絡先はサイトでも公開する。住所や電話の公開が伴うため、個人の自宅住所を安易にサイトへ掲示しない。
4. 情報変更時に更新、遅くとも**3年ごとに更新**する。同時に削除通知の受付フロー、再発侵害者ポリシー、適法な削除・異議申立て処理を用意する。

確認できなかった項目を「問題なし」や「修正済み」と断定しない。すべての事業で同じ年齢ゲート・購読文言を使い回さない。
