# QI の基準変更 qi-1.0 → qi-1.1（R2）：同じデータでの前後比較

- 実施日：2026-10-31
- 変更：R2「公式サイト・リポジトリへのリンクがある」。公式サイトの URL が無く、公式の GitHub リポジトリが正規の入口のツールは、それだけで減点しない。公式サイトがあるときは、そのリンクの有無を検査する。ミラーとみられるリポジトリは、正規の入口とみなさない（公式サイトが無く、ミラーなら不合格）。公式サイトの URL の形式が不正なら不合格
- 比較の方法：**同じ入力**（デフォルトブランチ 67ec8b5 のビルド、同じ `public/data`・`content/`）に、qi-1.0 の監査（2026-10-31-cddc94）と、qi-1.1 の監査（2026-10-31-823f8e）を実行し、ページごとに比べた。コンテンツ・データは変えていないため、差はすべて「基準の変更による分」で、ページの品質が実際に改善した分ではない
