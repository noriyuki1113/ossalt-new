# ossalt.jp 収益化ロードマップ

## 方針

ossalt.jp は当面、次の3本柱で収益化する。

1. サイト内の内製広告（回遊促進）
2. Google AdSense（審査通過後に導入）
3. VPSアフィリエイト

直接スポンサー販売は当面行わない。

## 1. 内製広告

トップ、SaaS代替詳細、ブログ記事末尾にサイト内おすすめ枠を置く。

目的:
- SaaS代替ページへの回遊
- OSS診断への誘導
- ツール一覧への回遊
- 将来のAdSense配置前に、広告枠の視認性とクリック傾向を確認する

Umamiイベント:
- `house_ad_impression`
- `house_ad_click`

主なパラメータ:
- `ad_id`
- `placement`

現在の内製広告:
- トップ: SaaS代替を探す
- SaaS代替ページ: OSS診断
- ブログ: ツール一覧

## 2. Google AdSense

AdSenseは運営者が申請し、審査通過後に導入する。

審査前はAdSense広告コードや広告枠を無理に本番へ入れず、
Googleから発行されるPublisher ID / AdSenseコードを確認してから実装する。

審査通過後に行うこと:
- AdSense用スクリプトをNext.jsのlayoutへ追加
- 広告ユニットを1〜2箇所から開始
- モバイルで本文を邪魔しない配置にする
- プライバシーポリシーをAdSense利用に合わせて更新
- 必要なCookie/同意管理を地域別要件に応じて対応
- 内製広告とAdSense広告を同じ位置に重複表示しない

初期配置候補:
- ブログ記事末尾
- SaaS代替詳細ページの比較表より下
- ツール詳細ページの本文下部

避ける配置:
- 比較表の中
- CTA直前に誤クリックを誘う配置
- ナビゲーションと見分けにくい位置
- 1ページに過剰な広告枠

## 3. VPSアフィリエイト

ツール詳細ページの `VpsRecommendation` から国内VPSへ誘導する。

現在:
- ConoHa VPS: A8リンク設定済み
- Xserver VPS: A8リンク設定済み
- KAGOYA CLOUD VPS: アフィリエイトURL未設定
- さくらのVPS: アフィリエイトURL未設定

Umamiイベント:
- `affiliate_click`

優先事項:
1. KAGOYA / さくらのVPSの提携状況を確認
2. 提携できた場合は正式なアフィリエイトURLを設定
3. provider別クリック数を30日単位で確認
4. クリックは多いが成果がない場合は文言・掲載位置を改善

## 売上目標

### 0 → 月1万円

- AdSense審査を通す
- 内製広告でサイト回遊を増やす
- VPSアフィリエイト4社の導線を完成
- Umamiで広告・アフィリエイトのクリックを継続計測

### 月1万円 → 月5万円

- 検索流入の多い記事・SaaS代替ページを増やす
- AdSenseの掲載位置を実測データで最適化
- アフィリエイトの成約ページを重点改善
- 広告収益だけでなくアフィリエイト成果比率も確認

### 月5万円 → 月10万円以上

- 高流入ページの広告配置をページ種別ごとに最適化
- OSS導入・セルフホスト関連の検索記事を拡充
- 成約率の高いVPSや関連サービスの比較コンテンツを増やす
- AdSense依存度が高くなりすぎないよう収益源を分散する

## 毎月見る数字

- サイト全体PV
- 検索流入
- `house_ad_impression`
- `house_ad_click`
- 内製広告CTR
- AdSenseのページRPM / 広告RPM / 推定収益（導入後）
- `affiliate_click`（provider別）
- アフィリエイト確定報酬

内製広告は収益そのものではなく、サイト内回遊と導線改善のために使う。
AdSenseとアフィリエイトは、読者体験を損なわない範囲で実測値を見ながら増やす。
