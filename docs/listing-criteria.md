# 掲載基準

2026-10-27 決定（運営者と相談のうえ）。公開ページの `/submit/`（掲載の条件）は、この文書の要約です。変更するときは、両方をそろえます。

## 1. 対象の種類
**掲載する**：
- サーバーで動かすソフト（Docker などで自前運用できるもの）
- データを手元に置くアプリ（SiYuan・Cryptomator・Super Productivity など。サーバーは不要でもよい）
- AIエージェント・AIアシスタント（OpenClaw・Hermes Agent など）

**掲載しない**：
- ライブラリ・SDK・フレームワーク（例：認証ライブラリ、エディタ部品、UIフレームワーク）。SaaSの「置き換え先」として使えないため
- 開発元のクラウド版しか使えないもの

## 2. 必須の条件（すべて満たすこと）
1. ソースコードが公開されている（ソース公開型は、その旨を注意して表示する）
2. GitHub でリポジトリが公開されている（数値を自動取得するため）
3. 上の「対象の種類」に当てはまる
4. 代わりになる有料サービス（SaaS）が特定できる
5. アーカイブ（開発終了）されていない
6. ライセンスが分かる（「不明」「unlicensed」は掲載しない）

## 3. 更新の線引き（最後のコミットからの期間）
| 期間 | 扱い |
| --- | --- |
| 1年未満 | 通常 |
| **1年以上** | 詳細ページの先頭に「更新が1年以上ありません」と、最終コミットの日付を**自動で表示**（掲載は続ける） |
| **2年以上** | **掲載の見直し対象**。運営者が「続ける」か「終了する」かを判断する。終了する場合は、転送（`data-source/redirects.json`）を設定する |
| アーカイブ | 掲載しない（既存の仕組みのとおり） |

公式が保守停止を告知している場合は、期間に関係なく「保守停止の公式警告」として表示する（根拠のURLと確認日つき）。

## 4. Star
- **下限は設けない。** Star数だけで落とさない。
- Star が 500 未満のものは、**掲載の理由を記録する**（例：日本のSaaSの代替として唯一、特定の用途で選ばれている、など）。記録先は `data-source/discovery/decisions.json` の `note`。

## 5. 注意の明記（必須）
次のいずれかに当てはまるものは、掲載できる。ただし**説明文に【注意】として、確認した事実を必ず書く**。書けない（確認できない）場合は掲載しない。
- 権限が広い（コマンド実行・ホスト上で動く・APIキーを扱う、など）。AIエージェントはほぼ該当
- 有料プランにしかない機能がある（SSO・権限管理など）
- ライセンスが複雑（デュアルライセンス・一部のディレクトリだけ別ライセンス・ソース公開型）
- 外部サービスや別のミドルウェアが必須（ClickHouse・従量課金のAPIキーなど）
- ホスト版・企業向け版が別に提供され、機能が異なる

## 6. 根拠と表記
- 根拠は、**公式のREADME・LICENSE・公式ドキュメント**。第三者の一覧（候補キューの記載）だけで掲載しない。
- 確認できないことは「未確認」とし、「非対応」「無し」にはしない（日本語UIは、確認できたときだけ書く）。
- 「置き換え元」のSaaSをREADMEが挙げていない場合は、**編集上の分類**であることを説明文に書く。
- 数値（Star・最終コミット・ライセンス表示）は、推測せず、GitHub APIの取得値だけを使う。

## 7. 優先順位（基準ではなく、追加する順番）
1. 需要がある領域の厚み（検索の実績・日本での利用）
2. まだ扱っていないSaaS（特に日本のSaaS）
3. Star・保守の状況

## 8. 運用
```
候補の洗い出し → 一次情報で確認（README・LICENSE）→ decisions.json に承認（approved）→ 追加 → データ更新で数値を取得 → 公開後に表示を確認
```
- 追加・削除・転送は、運営者の承認を得てから行う。
- 見直しは、最終コミット2年以上のものを四半期ごとに確認する。

## 9. 2026-10-27 時点の適合状況
- 最終コミットが1年以上前：9件（うち2年以上：4件：helpy・mailhog・papercups・crater）。1年以上のものには、先頭の表示が出る（この変更で追加）。
- 2年以上の4件は、掲載の見直し対象（運営者の判断が必要）。
- 「サーバーで動かす」から外れるものは、この基準で対象に含まれる（Cryptomator・Super Productivity・OpenClaw・Hermes Agent）。
- ライブラリ・SDK に当たる既存の掲載は、確認していない（別途、棚卸しが必要）。
