# UI刷新 Phase 3 実装計画（設計書・未実装）

2026-10-27。Phase 1（#50）・Phase 2（#51）の検証後に着手する。**この文書は計画であり、コードの変更は含まない。本番への反映はPhase 1・2の承認後。**

## 共通方針
- 既存の独自CSS・トークン・部品（`tool-brief.tsx`、`alternative-decision.tsx`、`ranking-tabs.tsx`）を再利用。新規の依存関係は入れない（TanStack Table等は、下記の表で必要と示せた場合のみ検討）。
- 既存の文章・根拠・評価データは削除しない。変えるのは表示順と視覚的な階層だけ。
- 「未評価」「未確認」は点数や良し悪しに変換しない（既存の `null` の扱いを踏襲）。
- JSON-LD・title・description・canonical・URLは変えない。変更ごとに「メタ情報の差分0」を確認する（Phase 1・2の検証と同じ手順：旧ビルドと新ビルドの全970ページを比較）。
- `prefers-reduced-motion` を尊重。装飾アニメーションは足さない。

## 前提：先に直す項目（Phase 3の前に）
- `/tools/` のCLS（下記の「残る問題」）。フォントの切り替わりで一覧上部が動く。
