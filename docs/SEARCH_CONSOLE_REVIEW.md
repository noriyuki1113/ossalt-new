# 解説のないツールページの検索掲載基準を決めるための確認

対象：P2-1。2026-10-09時点では Search Console の実績を取得していないため、掲載の基準は未決定。解説の有無だけで一括して noindex にしない。

## 運営者が用意するもの

Search Consoleで ossalt.jp のプロパティを選び、検索パフォーマンスの検索結果レポートを開く。対象をWeb検索とし、日付範囲を記録する。まず直近28日を確認し、短期間や少ないデータで判断できない場合は取得可能な長い期間も見る。未集計の日がある場合はその範囲を記録する。

ページの条件を `/tools/` を含むURLにして、ページ別の表をエクスポートする。ページURL、クリック数、表示回数、CTR、平均掲載順位、期間とフィルターを非公開の作業用の表に残す。国や端末を絞った場合は、その条件も記録する。

エクスポートした表に全URLが含まれるとは限らない。表にないURLを、表示回数ゼロと決めつけない。重要な候補は個別にページの条件を指定して調べる。

「ページのインデックス登録」のレポートも確認し、対象URLの登録状態と理由を記録する。重要な候補はURL検査で、Googleが選んだ正規URLとクロール時の状態を確認する。レポートとURL検査の確認日を残す。

## 公開データと照合する

`public/data/tools.json` の `id` がURLの `/tools/<id>/` に対応する。`content/tools/<id>.md` があれば手書き解説あり。`github_archived` が真のツールは、現状でもサイトマップから除外している。元データと生成データを混同しない。

非公開の表で、次の列を突き合わせる。

| 列 | 確認すること |
|---|---|
| ツールID・正規URL | 旧数字URLや転送元を、現行ページと重複して数えない |
| 解説の有無 | ファイルの有無だけでなく、読者の判断に必要な内容があるか |
| アーカイブ状態 | 開発終了の注意と現在のサイトマップの扱い |
| 検索実績 | 期間・国・端末などの条件をそろえて比較 |
| 登録状態 | noindex、重複、クロール済み未登録などを区別 |
| 検索意図 | 検索語に対して、ページの情報で答えられるか |
| 対応案・根拠 | 維持／解説改善／検索掲載を見送る／データ不足で保留 |

表示回数が少ないことと、ページの情報が不要なことは同じではない。重要な検索需要があるページは改善候補にする。実績がなく、取得期間も短いページは保留候補にする。クリック数や順位だけの固定した足切り値は、実績を見る前には決めない。

## 判断後の実装と確認

1. 運営者と、維持・改善・検索掲載見送りの基準と例外を決める。公開文書にはルールと理由を書き、実績の数値を転記しない。
2. サイトマップとページのrobots指定で、同じ基準を参照する。現時点ではツールページに解説の有無でnoindexを分ける実装はない。
3. 代表例で、維持するページはサイトマップ掲載・検索許可、見送るページはサイトマップ除外・noindexとなることを確認する。ページ自体は利用者向けに残す。
4. テスト・型検査・ビルドを確認し、専用ブランチからPRを作る。運営者のマージ後、公開HTMLとサイトマップを確認する。
5. 再クロール後にSearch Consoleで変化を確認する。SEO効果を公開直後に断定しない。

API・Markdownのヘッダー設定（P2-2）は別作業。[Cloudflare設定手順](SEARCH_NOINDEX_OPERATIONS.md)を参照。

OSS 20件（P2-3）は、この基準決定後に最新本番へ取り込み直す。今回の手順書の作成だけでは、P2-1・P2-3を完了にしない。
