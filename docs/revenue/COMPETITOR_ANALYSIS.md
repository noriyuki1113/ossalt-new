## 2. 言えること・言えないこと（批判役の整理）

**言えること**
- 英語圏の同種のディレクトリは「無料の掲載＋有料の目立つ枠（定額）」という形をとり、**順位は売らないと明記する**慣行がある。中立性を約束しても広告の商品は成り立ちうる。
- 価格の形（月額の定額、クリック課金なし）は参考になる。

**言えないこと**
- 実際に売れているか、何社が買っているか、売上。
- 英語圏・世界市場・自称の流入規模を前提にした価格を、日本語のみで流入の実数が不明なOSSALTに当てはめる根拠。

## 3. OSSALTとの違い

| 項目 | 競合（英語圏） | OSSALT |
|---|---|---|
| 言語・市場 | 英語・世界 | 日本語・日本のチーム |
| 強み | 掲載数、流入 | 日本のSaaSの代替、日本語対応の有無、ライセンスの区別（ソース公開型とOSS）、Cost Lab、国内VPS |
| 流入 | 自称で月数万〜十数万 | **このセッションでは不明** |
| 広告主の候補 | 世界のSaaS・開発者向けツール | 国内のVPS・ホスティング、OSSの商用版を売る企業、国内の導入支援企業 |

## 4. 結論（Revenue Council の判断）

- 価格を競合から決めない。OSSALTの料金は**公開せず個別見積もり**とし、4週間以上の画面内閲覧・クリックの実数がそろってから、最初の1社の試験掲載で決める（R6：HOLD）。
- 取り入れるもの：「順位・スコア・評価は売らない」の明記、定額・期間制、文字のみの軽い枠。
