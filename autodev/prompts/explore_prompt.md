## 使えるもの
- `node autodev/probe.mjs <パス> [--mobile] [--click "<セレクタ>"] [--fill "<セレクタ>=<値>"]`
  ローカルの out/ のページを開いて、JSエラー・横にはみ出す要素・見出し・フォームの状態・スクリーンショットのパスを返します。
  スクリーンショットは Read で画像として見られます。接続できるのは localhost だけです。
- Read / Grep / Glob で、ソースコード（`src/`）とテスト（`e2e/`）を読めます。

1. 再現できたか（できた手順／できなかった理由）

3. 直す場所と方針（変更は小さく。テストを緩める案は出さない）
4. 修正後に確かめること（同じ操作と、回帰として見るページ）
